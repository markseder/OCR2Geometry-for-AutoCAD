# OCR2Geometry for AutoCAD — v0.9.0

## Русский

Плагин превращает таблицы координат из изображений и текста в объекты AutoCAD. Разработчик: Pavel Matveev.

### Совместимость
- **AutoCAD 2020, полная версия, Windows 10/11 x64.**
- AutoCAD LT не поддерживается. Совместимость с другими версиями AutoCAD пока не заявлена.
- Требуется .NET Framework 4.7.2 или новее.
- Конечному пользователю не нужны Visual Studio, Inno Setup, Python или ручная загрузка через NETLOAD.
- Установщик содержит OCR-модель английских символов, библиотеки Tesseract и установщик Microsoft Visual C++ Runtime. Распознавание выполняется локально.

### Установка
1. Сохраните чертежи и закройте AutoCAD.
2. **Завершите все процессы `acad.exe`, включая фоновые.** Проверьте Диспетчер задач → Подробности. Если процессы остаются — перезагрузите Windows и запускайте установщик до открытия AutoCAD.
3. Запустите **OCR2Geometry-0.9.0-Setup-x64.exe** и подтвердите запрос администратора.
4. После завершения установки откройте AutoCAD 2020 и введите **`OCR2GEOMETRY`**.

Плагин устанавливается в `C:\Program Files\Autodesk\ApplicationPlugins\OCR2Geometry.bundle`. Если требуется перезагрузка Windows после установки зависимостей, выполните её.

### Как пользоваться
1. Снимите таблицу через Win+Shift+S и нажмите **Paste image**. Либо используйте **Select image** для PNG/JPG/BMP/TIFF.
2. Оставьте **Columns: Auto** и **Mode: Auto**, нажмите **Recognize OCR**.
3. Для неоднозначных трёх столбцов выберите **Point number + X + Y** или **X + Y + Z**. Два столбца означают X/Y с Z = 0; четыре — Point/X/Y/Z. Ручные варианты столбцов тоже доступны.
4. Сверьте результат с изображением: проверьте номера, минусы, десятичные разделители. Ячейки с автоматически восстановленными разделителями отмечаются отдельно; OCR-строки подсвечиваются для проверки.
5. Исправьте значения прямо в таблице. **Add row / Delete selected** добавляют/удаляют строки; **Swap X/Y** меняет координаты местами; **Move up / Move down** задают порядок контура.
6. Выберите **Points / Labels / Polyline**, при необходимости **Closed**, затем нажмите **Create objects**.

### Объекты и команды
- **OCR2GEOMETRY** — основная команда открытия плагина.
- **Points** — DBPoint на слое `Points`.
- **Labels** — подписи DBText на слое `Labels`; **Text height** задаёт высоту текста.
- **Polyline** — контур на слое `Polyline`, открытый или замкнутый. Вершины следуют порядку строк. Для открытого контура нужны минимум две разные точки, для замкнутого — три.
- При одинаковом Z создаётся плоская полилиния на этой высоте, при разном Z — 3D-полилиния.
- **Start number / Renumber from Start** — начальный номер и явная перенумерация строк. Нераспознанный номер можно ввести вручную.
- **Paste coordinates / Import CSV/TXT** — ввод координат из текста или файлов.
- **Export CSV** — экспорт таблицы Point,X,Y,Z.
- **OCR details** — текст распознавания и диагностика.
- **About / Donate** — сведения о разработчике и добровольная поддержка.

### Если что-то не работает
- Установщик просит закрыть AutoCAD: завершите оставшиеся `acad.exe` либо перезагрузитесь.
- Команда неизвестна: перезапустите AutoCAD 2020; проверьте установленную папку bundle и настройку APPAUTOLOAD. Старые копии плагина могут мешать загрузке. Не отключайте SECURELOAD.
- Строки не распознаны: проверьте выбранные столбцы, снимите более крупное и чёткое изображение, попробуйте Auto/Text/Table cells. Для Table cells нужна полная прямая сетка с внешними границами. Отправьте OCR details при обращении за помощью.
- Пропущен номер точки: проверьте изображение и заполните Point либо используйте Renumber from Start. Для подписей и экспорта CSV номера должны быть заполнены.
- OCR может ошибаться: перед созданием геометрии обязательно сверяйте координаты с источником.

Обновление: закройте все процессы AutoCAD и запустите новый установщик. Удаление: Параметры Windows → Приложения → OCR2Geometry for AutoCAD. Чертежи и экспортированные CSV не удаляются.

## English

**Supported: full AutoCAD 2020 on Windows 10/11 x64. AutoCAD LT is not supported; other AutoCAD releases are not yet supported by this package.** Requires .NET Framework 4.7.2 or later.

Download `OCR2Geometry-0.9.0-Setup-x64.exe`. Save drawings and close **all acad.exe processes**, including background processes (Task Manager → Details). Alternatively restart Windows and run setup before opening AutoCAD. Run setup, approve administrator elevation, then open AutoCAD 2020 and enter **OCR2GEOMETRY**. No Visual Studio, Inno Setup, Python or NETLOAD is needed by end users.

Paste a screenshot or select an image, leave Columns: Auto and Mode: Auto selected, and click Recognize OCR. Ambiguous three-column tables ask whether the layout is Point/X/Y or X/Y/Z. Two columns use X/Y with Z = 0; four use Point/X/Y/Z. Manual layouts remain available.

Review highlighted OCR rows, signs, decimal separators and point IDs against the source. Edit cells directly, use Swap X/Y as needed, and reorder rows with Move up/down to define the contour. Select Points, Labels and/or Polyline, choose Closed if needed, then Create objects. Output layers are Points, Labels and Polyline. Equal elevations produce an elevated lightweight polyline; varying elevations produce a 3D polyline.

Paste coordinates and Import CSV/TXT accept text data. Export CSV writes Point,X,Y,Z. Start number and Renumber from Start control numbering; Text height controls labels. OCR details provides recognition diagnostics. About / Donate shows developer information.

The installer bundles the local OCR model, Tesseract libraries and the Microsoft VC++ runtime installer. OCR runs locally. Restart AutoCAD if the command is unavailable, check APPAUTOLOAD and remove conflicting older plugin copies as appropriate; keep SECURELOAD enabled. Use Windows Apps settings to uninstall after closing AutoCAD.

Tested by the project owner in AutoCAD 2020. Download the EXE asset for installation; GitHub's Source code ZIP contains source files, not a ready installer.
